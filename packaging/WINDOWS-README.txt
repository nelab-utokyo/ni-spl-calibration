NI SPL Calibration — Windows x64

日本語
ZIPをすべて展開し、NI-SPL-Calibration.exe をダブルクリックしてください。
Python・uvのインストールは不要です。_internal フォルダも一緒に保持してください。
NI DAQ実機の利用には、機器・Windowsに対応したNI-DAQmxドライバが別途必要です。
既定の保存先は「ドキュメント / NI SPL Calibration / results」です。
WAV・NPZと、同梱ライブラリで動くPython生成関数を利用できます。
追加のPythonライブラリが必要な生成関数には、ソース版（uv）を使ってください。

English
Extract the entire ZIP and double-click NI-SPL-Calibration.exe.
Python and uv are not required. Keep the _internal folder beside the executable.
Physical NI hardware requires a separately installed compatible NI-DAQmx driver.
The default output folder is Documents / NI SPL Calibration / results.
WAV, NPZ and Python generators using bundled libraries are supported.
Use the source/uv distribution for generators requiring additional libraries.

Driver / ドライバ: https://www.ni.com/en/support/downloads/drivers/download.ni-daq-mx.html
Source / ソース: https://github.com/nelab-utokyo/ni-spl-calibration
